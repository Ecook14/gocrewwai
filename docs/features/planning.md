# Feature Deep Dive: Planning ⚓🧠

Planning is the pre-execution phase of a Gocrewwai crew where the engine intelligently decomposes complex goals into manageable, well-defined tasks. It ensures that the workload is optimally distributed among the participating agents.

---

> [!IMPORTANT]
> **Status: v1.0.0 (Stable).** Gocrewwai Planning mode utilizes **Autonomous Task Decomposition** to optimize crew execution before a single token is generated by an agent.

---

## 🏗️ Enabling Planning (Elite Style)

In Gocrewwai v1.0, planning is enabled with a single boolean flag in your `CrewConfig`. When enabled, the framework will:

```go
myCrew := gocrew.NewCrew(gocrew.CrewConfig{
    Agents:   []gocrew.CoreAgent{researcher, writer},
    Tasks:    []*gocrew.Task{highLevelMission},
    Planning: true, // Enable pre-execution planning
})
```

## 🧠 The Planning Lifecycle

1. **Analysis**: The engine analyzes the `Goal` of the crew and the `Backstory` of each agent.
2. **Decomposition**: It breaks the high-level mission into specific, actionable sub-tasks.
3. **Assignment**: It determines the optimal agent-task match based on individual agent capabilities and tool sets.
4. **Context Mapping**: It defines the data dependencies between the sub-tasks to ensure correct flow execution.

## 📈 Planning Benefits

### 🏎️ 1. Execution Optimization
By planning ahead, the engine can identify tasks that can be performed in parallel, significantly reducing the total execution time of the crew.

### 🛡️ 2. Hallucination Reduction
Detailed planning provides a clear roadmap for the agents, reducing the likelihood of them drifting off-topic or hallucinating details that aren't part of the mission.

### 📊 3. Human Oversight
The generated "Plan" is available in the **Dashboard** before execution begins, allowing developers to review and adjust the roadmap if necessary.
