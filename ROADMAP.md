# Roadmap (2026)

Status: **Beta**. Targeting v1.0.0.

## ✅ Shipped (v0.9.0)

- [x] Agent-to-Agent (A2A) communication
- [x] Multi-crew flow combinators (`Switch`, `Map-Reduce`, `Iterate`)
- [x] Enhanced Docker/E2B sandboxing
- [x] Dashboard metrics (cost, token usage, latency)
- [x] `core.Agent` interface standardization

## 🔜 Mid-Term (v1.0.0-beta)

- [ ] Native WASM multi-runtime
- [ ] Streaming reasoning (real-time thinking steps)
- [ ] Vector database adapters (Qdrant, Milvus, Chroma, etc.)
- [ ] Industry-specific CLI templates (Finance, Healthcare, E-commerce)

## 🔭 Long-Term (v1.0.0 Stable)

- [ ] Distributed crew execution across multiple nodes
- [ ] Agent governance / policy-based constraints
- [ ] Multi-modal native core (vision, audio, video)
- [ ] Enterprise API gateway (`gocrew serve`)
